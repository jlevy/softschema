packages/python/src/softschema/validate.py (or pipeline.py) plus the __init__.py export.

Validate and return the payload values; raise on anything short of outcome == 'valid'. The raised error should carry the ArtifactValidationResult so a caller can inspect the records.

Why: there is no strict consuming call today. read_frontmatter_doc / read_yaml_doc are strict but give raw frontmatter with no contract enforcement; validate_artifact enforces the contract but is a checker. So 'read this artifact I already validated and give me its values' has no single call, and a consumer that forgets to check outcome gets values=None and a downstream TypeError: 'NoneType' object is not subscriptable.

Additive and separable -- can be cut from the release without affecting the rest of the epic. Spec D5.
