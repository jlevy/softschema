Qodo finding #6 on PR #64: https://github.com/jlevy/softschema/pull/64#discussion_r4372746163.

`ensure-gh-cli.sh` runs under `set -euo pipefail` (line 16). `installed_gh_version` (lines 115-117) pipes `"$1" --version 2>/dev/null` into `awk`. With `pipefail`, a `gh` on PATH that exits non-zero on `--version` fails the pipeline. The assignment `GH_CURRENT="$(installed_gh_version "$GH_PATH")"` (line 125) then aborts the script under errexit, so the branch that installs the pinned gh never runs. The same function feeds `GH_RESOLVED_VERSION` at line 231.

Locations at main 8085986: `.claude/scripts/ensure-gh-cli.sh` and `.codex/ensure-gh-cli.sh`, identical, both generated by `tbd setup --auto`.

Fix upstream in tbd (https://github.com/jlevy/tbd), for example `{ "$1" --version 2>/dev/null || true; } | awk 'NR==1 {print $3}'`. Then run `tbd setup --auto` here after that tbd release, and close this bead with that commit. Not edited in this repo.
