Qodo finding #6 on PR #64 (thread https://github.com/jlevy/softschema/pull/64#discussion_r4372746163). installed_gh_version runs "$1" --version | awk under set -euo pipefail and GH_CURRENT="$(installed_gh_version ...)" fails the script when the existing gh exits non-zero, so the install-pinned-gh branch never runs (.claude/scripts/ensure-gh-cli.sh:115-116 and .codex/ensure-gh-cli.sh:115-116). The files are generated by tbd setup, so the fix belongs upstream: e.g. { "$1" --version 2>/dev/null || true; } | awk 'NR==1 {print $3}'. Not edited in this repo.
